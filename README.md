# Student Course Management System (C++)

A console-based C++ student course management system demonstrating object-oriented programming, STL containers, file I/O, input validation, and GPA calculations.

## Features

- Add student records
- Display all students
- Search for a student by ID
- Calculate average GPA
- Save student records to a text file
- Validate GPA input
- Menu-driven console interface

## Technologies

- C++
- Object-oriented programming
- STL `vector`
- File I/O
- Basic input validation

## Files

- `main.cpp` — program entry point and menu logic
- `Student.h` — Student class declaration
- `Student.cpp` — Student class implementation and file output
- `students.txt` — sample student data

## How to Compile

Using a C++ compiler such as g++:

```bash
g++ main.cpp Student.cpp -o student_management
./student_management
```

## Purpose

This project was created as a portfolio project to demonstrate foundational C++ programming concepts and provide a practical example of organizing a small multi-file software application.
